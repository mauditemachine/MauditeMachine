MM-STUDIO

The home page of mauditemachine.com

MM-STUDIO by Maudite Machine is a 3D studio played in the browser: the MM-RYTM drum machine, the MM-ARP synth and the MM-DECKS DJ decks and mixer, all in time. It is free, with no account and nothing to install. Mika designed and built the site and every machine on it.

MM-RYTM
Drum machine: 8 voices (BD, SD, CH, OH, CP, TOM, HT, CY), 16 steps, parameter locks, 16 patterns, a SYNTH or SAMPLE layer per voice, voice and global effects
MM-ARP
Synth: two oscillators and a sub, ladder filter with four modes, arpeggiator, 8 chord pads in F# minor, OVERDRIVE, CHORUS, DELAY, REVERB
MM-DECKS
Two to four DJ decks and a mixer (GAIN -12 to +12 dB, three band EQ, VU meters) that also takes MM-RYTM and MM-ARP, a sampler in each deck
MIDI
MIDI LEARN for every parameter; ready-made Melbourne Instruments Roto-Control setups, downloaded from the MIDI panel and imported in ROTO-SETUP, no MIDI LEARN needed
Also
UNDO and REDO, presets saved in the browser, Dark and Light appearances
Runs on
Any browser with WebGL 2 and the Web Audio API, on a computer or a phone; Web MIDI in Chrome, Edge, Opera and Firefox
Built with
Three.js, Web Audio API, Web MIDI API
Design and build
Mika (Maudite Machine)
